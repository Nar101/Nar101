## 🌱 最近最想做好的一件事

**把我自己的 AI 工作台，变成你也能用的工作台。**

换个 AI、开段新对话，又得从头解释自己是谁、在做什么、上次说到哪了。有时候光是找回状态，就已经不太想干了。

我想把这部分麻烦省掉。理想中的用法是：你把仓库发给 AI，告诉它你的目标、常用工具和手头的项目，它就能带你一步步搭出适合自己的工作台。资料、决定和进展都留得下来，下次接着做。

我已经在用自己的版本，现在正准备把它整理成开源版。**还在准备中，做好了会放到这里。**

## 🧩 已经做出来的东西

### 📚 [Learn Anything](https://github.com/Nar101/learn-anything)

给「我好像懂了」加一道检查。

把想学的东西交给 AI，让它分段讲、让你自己答，再根据你的表现调整进度。还会安排复习、换个场景继续练。毕竟聊天时一直点头，和离开对话后自己能做出来，还是两回事。

[中文说明与安装 →](https://github.com/Nar101/learn-anything/blob/main/README.zh-CN.md)

### 🧩 [产品需求 AI 工作流](https://github.com/Nar101/product-requirement-ai-workflow)

「我想做个这个功能。」好，然后呢？

谁会用、解决什么问题、方案怎么选、做到什么程度，这套工作流会让 AI 陪你一步步往下走，直到原型和需求文档。需要拍板的地方，还是你来。

### ✍️ [微信公众号草稿工具](https://github.com/Nar101/wechat-official-account-draft-publisher)

写完文章以后，还能少折腾一点。

把 Markdown / HTML 和图片送进公众号草稿箱，顺便检查配置缺了什么。需要公众号接口权限；草稿传好后，自己看一遍，再正式发布。

### 🗒️ [Daily Note Window](https://github.com/Nar101/Daily-Note-Window)

突然想到一点东西，先记下来再说。

双击 Option，今天的 Obsidian 日记就出现在面前。用的还是原生编辑器，写的还是自己的笔记。macOS Beta，需要 Obsidian，暂时要按仓库说明手动安装。

## 🔧 还有几个顺手的小工具

- [Media Saver](https://github.com/Nar101/yt-dlp-raycast)：在 Raycast 里下载媒体。关掉窗口再回来，任务还在，进度、失败原因和重试也有。基于开源项目改进，目前通过开发模式安装。
- [Obsidian AI 定制开发](https://github.com/Nar101/develop-obsidian-workbench)：想给 Obsidian 加点自己的功能？让 AI 先看清已有配置，再动手改，最后到实际应用里试。
- [新标签页打开链接](https://github.com/Nar101/open-links-in-new-tabs)：很小的一个插件。在 Obsidian 阅读模式里点内部链接，会开新标签页，手头这篇不用关。
