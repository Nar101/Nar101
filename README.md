# Nar / 那不然 👋

**我想重新设计 AI 时代，个人与团队的工作方式。**

我是做产品的，也写文章、做工具。平时琢磨得最多的是：怎么让 AI 真正参与工作，让一个人和一支小团队，也能把想做的事做出来。

这里是我的作品集。学习、处理需求、写作、随手记东西，都是我和 AI 一起动手的地方。我想把这些作品一个个打磨好，也希望你能从中找到自己用得上的东西。

[个人网站与文章 ↗](https://nar101.com) · [全部公开仓库 ↗](https://github.com/Nar101?tab=repositories&type=public)

## 🌱 最近在做：个人 AI 工作台

换一个 AI、开一段新对话，常常又得从头解释自己在做什么。资料散在不同地方，昨天做到哪一步，也得重新找。

我在把自己使用的工作台整理成开源版。想实现的体验很简单：**把仓库发给你的 AI，告诉它你的目标、常用工具和手头的项目，它就能带你一步步搭出适合自己的工作台。**

让资料、决定和进展留得下来，下次接着做。目前在整理第一版，开源版准备中。

## 可以从这几件作品开始

### 📚 [Learn Anything](https://github.com/Nar101/learn-anything)

读完一篇文章、听懂一段解释，离自己能用出来，可能还差几次练习。

给 AI 一个学习目标，或者一份你想学的资料。这套教学指引会让它分段讲解、让你独立作答，再根据你的表现调整进度，安排复习和换个场景的练习。

[中文说明与安装 →](https://github.com/Nar101/learn-anything/blob/main/README.zh-CN.md)

### 🧩 [产品需求 AI 工作流](https://github.com/Nar101/product-requirement-ai-workflow)

一句「我想要这个功能」，后面还有很多问题：谁会用？解决什么麻烦？方案怎么选？做到什么程度算完成？

让 AI 按步骤帮你梳理这些问题，逐步推进需求分析、方案讨论、原型和需求文档。需要取舍的地方，由你来定。

### ✍️ [微信公众号草稿工具](https://github.com/Nar101/wechat-official-account-draft-publisher)

文章写好了，图片也齐了，接下来把它们送进公众号草稿箱。

这个工具处理 Markdown / HTML、图片上传和草稿创建，也检查账号配置是否齐全。需要公众号接口权限；你检查草稿后，再自行正式发布。

### 🗒️ [Daily Note Window](https://github.com/Nar101/Daily-Note-Window)

突然想到一点东西，双击 Option，今天的 Obsidian 日记就出现在面前。

窗口里用的还是 Obsidian 原生编辑器，直接写进自己的笔记。当前为 macOS Beta，需要 Obsidian，并按仓库说明手动安装。
