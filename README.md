## 🌱 最近在做

**把我自己的 AI 工作台，整理成别人也能用的开源版本。**

换个 AI、开段新对话，又得从头解释自己是谁、在做什么、上次说到哪了。我想把这部分麻烦省掉。

理想中的用法是：你把仓库发给 AI，告诉它自己的目标、常用工具和手头的项目，它就能带你一步步搭出适合自己的工作台。资料、决定和进展留得下来，下次可以接着做。

我已经在用自己的版本，开源版还在准备中。

## 🧩 工具与方法

### 📚 [Learn Anything](https://github.com/Nar101/learn-anything)

让 AI 带着你学，也检查你到底学会了没有。

从一个学习目标或一份资料开始，分段讲解、独立回答、练习和复习，再根据你的表现调整进度。除了当下能答出来，也会换个场景，让你试试能不能自己用。

[中文说明与安装 →](https://github.com/Nar101/learn-anything/blob/main/README.zh-CN.md)

### 🧩 [产品需求 AI 工作流](https://github.com/Nar101/product-requirement-ai-workflow)

从“我想做个功能”，一步步走到原型和需求文档。

谁会用、解决什么问题、方案怎么选、做到什么程度，这套工作流让 AI 陪你逐项讨论和推进。需要拍板的地方，还是你来。

### ✍️ [微信公众号草稿工具](https://github.com/Nar101/wechat-official-account-draft-publisher)

把写好的文章和图片送进公众号草稿箱。

支持 Markdown / HTML，也会检查配置缺了什么。需要公众号接口权限；草稿传好后，自己检查，再正式发布。

### 🗒️ [Daily Note Window](https://github.com/Nar101/Daily-Note-Window)

双击 Option，打开今天的 Obsidian 日记。

用的是 Obsidian 原生编辑器，写的还是自己的笔记。当前为 macOS Beta，需要 Obsidian，按仓库说明手动安装。

## 🔧 其他小工具

- **[Media Saver](https://github.com/Nar101/yt-dlp-raycast)**：在 Raycast 里下载媒体。关掉窗口再回来，任务还在，也能查看进度、失败原因和重试。基于开源项目改进，目前通过开发模式安装。
- **[Obsidian AI 定制开发](https://github.com/Nar101/develop-obsidian-workbench)**：让 AI 先了解已有配置，再定制功能，最后到实际应用里检查效果。
- **[新标签页打开链接](https://github.com/Nar101/open-links-in-new-tabs)**：在 Obsidian 阅读模式中点击内部链接，会打开新标签页，保留手头正在看的笔记。
